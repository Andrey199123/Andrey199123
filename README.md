# Andrey Vasilyev

I build software for practical problems—from food-pantry operations and digital access to student planning and computer vision.

My work spans TypeScript/React applications, Python, and scientific computing. I care about the complete path from an idea to a usable interface: the backend, deployment, and the people using it.

## Selected projects

### DriveSafe AI
Camera-based monitoring prototype and Congressional App Challenge district winner. React and TypeScript frontend, server-side vision integration with Convex, PWA support, and accessibility tests. An experimental software project, not a validated driving-safety device.

[Explore the app](https://drivesafe-ai.vercel.app) · [Read the code](https://github.com/Andrey199123/DriveSafe-AI#readme)

### Arc
A team-built planning app that connects goals to milestones, weekly tasks, and a calendar. My work includes frontend-to-backend integration, deployment, and MicroDC inference integration. The public repository showcases the frontend; the production backend is private.

[Explore Arc](https://arcgoalgetter.com) · [Technical overview](https://github.com/Andrey199123/Arc_MicroDC#readme)

### Poverello Pantry
A team-built ordering and inventory system for food-pantry operations, with a points-based client shop, staff dashboard, and kiosk interface. The operational deployment requires authentication; the public demo is separate.

[Try the public demo](https://poverello.vercel.app) · [Project overview](https://github.com/Andrey199123/Storefront#readme)

### Bytes for Better Lives
Website and chapter-management platform for a student-led digital-equity nonprofit. Plain JavaScript frontend, Firestore-backed content, chapter-scoped administration, and subdomain routing. I incorporated the nonprofit and obtained its 501(c)(3) status; the organization grew from an existing school club.

[Visit the organization](https://bytesforbetterlives.org) · [Explore the repository](https://github.com/Andrey199123/bytesforbetterlives#readme)
